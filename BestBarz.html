1. Showing and hiding the bars

There is one bar per screen edge: Left, Top, Right and Bottom. Move the pointer to an edge and its bar appears; move away and it hides.

  • The whole edge opens the bar, wherever its buttons are. The corners open none, so reaching a corner doesn't open two bars at once.
  • Once open, a bar stays open while the pointer is anywhere along its edge strip, so you can travel to its buttons without it closing.
  • When a fullscreen app is in front (a game, a video, a remote desktop), the bars stay hidden.
  • Holding Ctrl while reaching an edge always opens its bar, even over a fullscreen app.
  • The bar on the Windows taskbar's side opens only with Ctrl, so it doesn't pop up every time you head for the taskbar. With Ctrl held, the taskbar itself also opens it.
  • Ctrl+Alt+B hides every bar until you press it again.
  • With Show bars over apps without Ctrl turned off in Settings, the bars open by themselves only while the desktop or the taskbar has the focus; over any other app they need Ctrl.
The bars normally sit beside the Windows taskbar. A bar set to Cover the taskbar uses the whole screen edge instead and appears over it.

2. The right-click menu

Right-click anywhere on a bar — a button, a group, a separator or the empty space — to get its menu. Commands about an item act on the one you clicked; new items are placed right after it (or at the end, when you clicked the empty space).

CommandWhat it does
Cut / Copy / PasteMove or duplicate items between bars and groups. After Cut, the item is pasted once; after Copy, it can be pasted as many times as you like.
Paste Into GroupOn a group: puts the cut or copied item inside it.
Edit… / Rename…Edit a button or separator; on a group, rename it.
Arrange modeReorder items (see Arrange mode).
Add Button…Create a button by hand.
Add Programs…Pick programs from the Start menu (see Buttons).
Add Group ▸Create an empty group, a group of programs, or a ready-made one (see Groups).
Add SeparatorA thin divider; edit it to give it a label.
RemoveDelete the item, after confirming.
Global ▸Settings, Help, Hide bars, turning each bar on or off, and Exit BestBarz. The same menu opens from the tray icon (left or right click).

A menu closes with Esc, with a click elsewhere, or when you switch to another app.

3. Buttons

FieldMeaning

TargetThe program, document, folder or address to open. … browses for a file.
ArgumentsPassed to the program, e.g. mmsys.cpl for control.exe.

  • Paths may use environment variables — %SystemRoot%, %AppData%, %UserProfile%… — so a button keeps working on another PC or user account.
  • Quotes around a pasted path (as Explorer's Copy as path adds) are removed.
  • Each button shows its target's icon; Control Panel applets (.cpl) show their own.
  • You can also drop files or folders from Explorer onto a bar to add them.

Add Programs…

Lists the programs of the Start menu (uninstallers and documentation left out). Type to search, tick the ones you want — ticks survive a new search — and press Add.

4. Groups

A group is a button with an arrow; clicking it opens a popup with more items. The popup has its own right-click menu, much like the bar's. Groups cannot contain other groups.

Add Group ▸

EntryCreates
Empty…An empty group; you choose the name.
From programs…A group with programs picked from the Start menu; the name suggested is their common Start menu folder.
System utilitiesControl Panel, Programs and Features, System Properties, Environment Variables, Disk Cleanup.
Admin utilitiesComputer, Device and Disk Management, Event Viewer, Registry Editor, Task Manager, Resource Monitor, System Information.
C-Panel appletsEvery Control Panel applet installed on this PC.
System pathsWindows, Program Files, ProgramData, the user profile, AppData, Temp, Start menu folders…

The ready-made groups are a quick source of links: copy the items you want to where you want them, then remove the group. If a name is taken, a number is added: System1, System2…

Other ways to fill a group: Paste Into Group, or, in Arrange mode, dropping an item on the group (or moving it next to the group and pressing Enter).

5. Arrange mode

Right-click an item and choose Arrange mode. The item gets a blue frame, the bar a blue border, and (unless turned off in Settings) a small help window appears.

KeyAction
← ↑ PgUpMove one place back
→ ↓ PgDnMove one place forward
Home / EndMove to the start / end
Next to a groupThe group turns orange: Enter drops the item inside; the same arrow again skips over it
EnterSave and finish
EscCancel, restoring the previous order
MouseDrag to reorder; drop on a group to move the item inside

7. Configuration files

Everything is kept in plain XML files, by default in a Config folder next to BestBarz.exe:

Config\
  _global.xml          settings shared by all bars
  Left\  Top\  Right\  Bottom\
    _bar.xml           the bar's settings and buttons
    <Group>.xml        one file per group
  • The folder name decides the edge; other folders are ignored. To switch a whole bar, rename folders — e.g. Top → Top-Work and Top-Home → Top.
  • Changes made by hand are applied automatically within a couple of seconds.
  • Some options exist only in the files: in _bar.xml, buttonColor, buttonTextColor, separatorTextColor, separatorTextAlign, showBorders; in _global.xml, showDelay, hideDelay, pointerDistance and maxButtonWidth (one value per edge: Left, Top, Right, Bottom), maxOpacity, protectTopLeftCorner and protectTopRightCorner.
  • Colors are a Windows color name (Control, SteelBlue) or R;G;B.

Another configuration folder

BestBarz.exe --config "%AppData%\BestBarz"

Environment variables are allowed; a relative path is taken from the program's folder. The folder is created if missing; an empty one starts with default bars.
